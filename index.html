CONFIGURATION REQUISE

Connecter Supabase

Le live multi-téléphones a besoin de Supabase Realtime. Le package contient déjà le SQL et le fichier de configuration.

  1. Exécute supabase.sql dans ton projet.
  2. Renseigne l’URL et la clé anon dans config.js.
  3. Dans Supabase > Authentication > Users, crée ton compte formateur.
  4. Déploie le dossier sur ton hébergeur.
